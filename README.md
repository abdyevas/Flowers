# 🌸 Wanna Buy Me Some Flowers?

*A tiny page with one question, four buttons, and one of them runs away.*

**[✨ Try it live](https://abdyevas.github.io/Flowers/)**

</div>

## 🎬 How it works

- 🌷 Click **Yes** (or **Maybe later**) and get a shower of flowers.
- 🏃 Try to click **No**. Good luck.
- 👋 **Sorry, never...** just disappears.

## 🛠 Built with

Plain **HTML**, **CSS** and **vanilla JavaScript**. No frameworks, no dependencies, no build step.

## 🚀 Run it locally

```bash
git clone https://github.com/abdyevas/Flowers.git
cd Flowers
```

Open `index.html` in your browser. That's it.
